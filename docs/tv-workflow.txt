========================================================================
  MEDIA SERVER — DOWNLOAD & CLEANUP GUIDE
  homelab quick reference
========================================================================

Two types of downloads, handled differently:

  MOVIES  -> download with label "movies" -> appears in Plex directly
  SERIES  -> download with label "tv" -> run the organizer script -> Plex

The server does all the work; you just kick off each step.


########################################################################
#  MOVIES  (the simple case)
########################################################################

1. Deluge (http://deluge.local): add torrent, set label = movies, wait 100%.
2. Plex (http://plex.local): Movies library -> "..." -> Scan Library Files.
3. It appears. Done.

Movies download straight into the Plex library, so nothing else is needed.

DELETE A MOVIE WHEN DONE:
  Deluge -> right-click the torrent -> "Remove With Data".
  That's it — the file is gone and space is freed.
  (Then optionally scan Plex so it drops from view.)


########################################################################
#  SERIES  (needs one organizing step)
########################################################################

------------------------------------------------------------------------
STEP 1 — DOWNLOAD IN DELUGE
------------------------------------------------------------------------
1. Open http://deluge.local
2. "Add" -> paste magnet link (or upload .torrent).
3. Set the label to:   tv
      (right-click the torrent -> Label -> tv)
4. Wait for 100%.

   Tip: 1080p releases. x265/HEVC plays fine on your TVs; if a file
   ever stutters on some device, grab an x264/H.264 version instead.


------------------------------------------------------------------------
STEP 2 — CONNECT TO THE SERVER
------------------------------------------------------------------------
Open Terminal on the Mac:

    ssh george@192.168.0.45


------------------------------------------------------------------------
STEP 3 — FIND THE EXACT FOLDER NAME
------------------------------------------------------------------------
    ls "/mnt/data_1tb/media/tv/"

Copy the download folder's exact name
(e.g.  Some Show 2026 S01 1080p WEB x264-GROUP ).


------------------------------------------------------------------------
STEP 4 — PREVIEW WHAT THE SCRIPT WILL DO (safe, changes nothing)
------------------------------------------------------------------------
    ~/homelab/scripts/organize-series.sh "PASTE FOLDER NAME HERE"

Prints the plan: detected show, year, where each episode goes.
Nothing moves yet. Check the show name / season look right.


------------------------------------------------------------------------
STEP 5 — RUN IT FOR REAL
------------------------------------------------------------------------
    ~/homelab/scripts/organize-series.sh --go "PASTE FOLDER NAME HERE"

Creates  Show Name (Year)/Season 0X/  , moves the episodes in,
and deletes the empty download folder.


------------------------------------------------------------------------
STEP 6 — REMOVE THE TORRENT FROM DELUGE
------------------------------------------------------------------------
Moving the files breaks the seed, so Deluge shows an "error" for it.
That's expected. Clean it up:

  http://deluge.local -> right-click the torrent -> "Remove"
  (no data needed — the video files are already moved to the library)


------------------------------------------------------------------------
STEP 7 — SCAN THE LIBRARY IN PLEX
------------------------------------------------------------------------
1. http://plex.local
2. Hover the "TV Shows" library -> "..." -> "Scan Library Files".
3. Wait 30-60s, refresh. The show appears with poster + episodes.


------------------------------------------------------------------------
DELETE A SERIES WHEN DONE  (frees disk space)
------------------------------------------------------------------------
The series files live in the Plex library (1 TB disk), NOT in Deluge —
so you delete them directly:

    rm -rf "/mnt/data_1tb/media/tv/SHOW NAME (YEAR)"

  Example:
    rm -rf "/mnt/data_1tb/media/tv/I Will Find You (2026)"

Then scan Plex again (Step 7) so it drops the removed show from view.

  (If you already removed the torrent in Step 6, there's nothing left
   in Deluge to clean up. If not, remove it now too.)


------------------------------------------------------------------------
IF A NEW SHOW DOESN'T APPEAR AFTER SCANNING
------------------------------------------------------------------------
Brand-new shows sometimes fail to auto-match. Try, in order:

  a) Wait a minute and scan again (Step 7).

  b) Confirm Plex can see the files (should list them):
       docker exec plex ls "/tv/SHOW NAME (YEAR)/Season 01/"

  c) In Plex, if the folder shows unmatched:
       click the show -> "..." -> "Match" -> search the title -> pick it.


########################################################################
#  ONE-TIME SAFETY SETTING (set once, then forget)
########################################################################

Keep Plex from ever deleting your files itself:

  Plex -> Settings -> Library -> "Allow media deletion" -> OFF

With this OFF, Plex only DISPLAYS your files, never deletes them.
You stay in full control: deletion happens only via Deluge
("Remove With Data" for movies) or  rm  (for series).


########################################################################
#  QUICK VERSION (once it's muscle memory)
########################################################################

MOVIE:
  1. Deluge: add, label = movies, wait 100%
  2. Plex: Movies -> ... -> Scan
  Delete: Deluge -> Remove With Data

SERIES:
  1. Deluge: add, label = tv, wait 100%
  2. ssh george@192.168.0.45
  3. ls "/mnt/data_1tb/media/tv/"
  4. ~/homelab/scripts/organize-series.sh "FOLDER"        (preview)
  5. ~/homelab/scripts/organize-series.sh --go "FOLDER"   (do it)
  6. Deluge: remove the torrent
  7. Plex: TV Shows -> ... -> Scan
  Delete: rm -rf "/mnt/data_1tb/media/tv/SHOW (YEAR)"  + scan Plex
