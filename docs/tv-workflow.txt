THREE WAYS TO GET SOMETHING INTO THE LIBRARY
  A) MANUAL PICK + AUTO HANDLING  (the default — most control)
  B) FULLY AUTOMATED              (best for ongoing weekly shows)
  C) SCRIPT FALLBACK              (for what the *arrs can't match)

  Whichever you use: ONE SHOW, ONE PATH. Never mix them for the same
  title, or you end up with duplicate files under two naming schemes.

########################################################################
#  A) MANUAL PICK + AUTO HANDLING   (default)
########################################################################

You choose the release; the stack does the organising and subtitles.
Worth it because a human reading seeder counts beats an automatic
search that ranks by quality and can't see swarm health.

------------------------------------------------------------------------
1. FIND AND DOWNLOAD
------------------------------------------------------------------------
  Deluge -> Add -> paste magnet.
  Label:  tv-sonarr     (series)
          movies-radarr (films)

  These labels leave the file on the 500 GB disk so Sonarr/Radarr can
  import it. Do NOT use the plain `tv` / `movies` labels here — those
  write straight into the library and bypass the *arr apps entirely.

  Wait for 100%.

------------------------------------------------------------------------
2. ADOPT IT
------------------------------------------------------------------------
  Sonarr -> Wanted -> Manual Import      (or Radarr -> Movies -> Manual Import)
  Browse to  /downloads/tv-sonarr/  (or /downloads/movies-radarr/)
  Pick the series/film it belongs to, confirm the episode mapping,
  and import.

  If the show isn't in Sonarr yet, add it first:
  Series -> Add New -> search -> Monitor: None -> Add.

------------------------------------------------------------------------
3. SUBTITLES HAPPEN BY THEMSELVES
------------------------------------------------------------------------
  Bazarr picks up anything Sonarr/Radarr manage and searches for
  English + Greek. Nothing to do.

  Check progress: Bazarr -> Series / Movies
  Outstanding items sit in Bazarr -> Wanted and get retried on a
  schedule. Greek coverage is thinner than English — that's the
  subtitle ecosystem, not a misconfiguration.

  To force a search for one item:
  Bazarr -> open the series -> magnifying glass on the episode.

------------------------------------------------------------------------
4. PLEX
------------------------------------------------------------------------
  Plex -> the library -> "..." -> Scan Library Files.
  (Or wait for its own scan timer.)

  Subtitles do NOT auto-enable on playback. In the player, click the
  subtitle icon and pick a track. To make them default:
  Plex -> Settings -> Account -> Languages -> preferred subtitle
  language + "Always enabled".


########################################################################
#  B) FULLY AUTOMATED
########################################################################

Best for shows that are still airing — you add it once and forget.

  1. Sonarr -> Series -> Add New -> search the show
  2. Root Folder: /media/tv
     Monitor: choose deliberately —
       "Future Episodes"  = only new ones as they air  (usually what you want)
       "All Episodes"     = hunts the entire back catalogue immediately
       "Pilot Episode"    = just S01E01, good for testing
     Quality Profile: pick one
  3. Add.

  From then on Sonarr checks the indexers on a schedule, grabs, hands
  to Deluge under `tv-sonarr`, imports, and Bazarr subtitles it.

  Same in Radarr for films (Movies -> Add New).

------------------------------------------------------------------------
WHEN NOTHING DOWNLOADS
------------------------------------------------------------------------
Sonarr's queue will happily sit at empty-progress forever if the
release it grabbed has no seeders. Check DELUGE, not Sonarr:
  Deluge -> select the torrent -> Status tab
  Name still a hash + Availability 0.000 + 0 seeds = dead release.

Fix:
  1. Sonarr -> Activity -> Queue -> X on the row
     Removal Method:   Remove from Download Client
     Blocklist Release: Blocklist and Search
     (this blocks that release AND auto-searches for another)

  2. If the retry also stalls, use INTERACTIVE SEARCH:
     Sonarr -> the series -> click the EPISODE TITLE (not any icon)
     -> "Search" tab.
     This opens the full release table with a PEERS column.
     Sort by it and pick something with real seeders.

     (The magnifying glass on an episode ROW runs an *automatic*
      search — it just shows a toast. It is not the interactive one.)

  3. If every release on the page shows 0 seeders, the content simply
     isn't being seeded. Old or obscure titles on public trackers are
     the usual case. Nothing is broken.


########################################################################
#  C) SCRIPT FALLBACK  (organize-series.sh)
########################################################################

For series the *arr apps cannot match — Greek-language shows in
particular are often missing from TheTVDB or listed under a title that
defeats automatic matching.

  1. Deluge: add torrent, label = tv, wait 100%
     (plain `tv` — this one moves into the library directly)

  2. ssh george@192.168.0.45

  3. ls "/mnt/data_1tb/media/tv/"
     copy the exact folder name

  4. PREVIEW (changes nothing):
     ~/homelab/scripts/organize-series.sh "PASTE FOLDER NAME"

  5. RUN:
     ~/homelab/scripts/organize-series.sh --go "PASTE FOLDER NAME"

     Creates  Show Name (Year)/Season 0X/ , moves episodes in, removes
     the empty download folder.

  6. Deluge: remove the torrent (moving files breaks the seed — the
     "error" state is expected). No data to delete; files are moved.

  7. Plex: TV Shows -> "..." -> Scan Library Files

  NOTE: Bazarr will NOT subtitle this — it only sees what Sonarr and
  Radarr manage. Either accept manual .srt files, or use path A and
  Manual Import instead.

------------------------------------------------------------------------
FOLDER STRUCTURE THE *ARRS EXPECT
------------------------------------------------------------------------
  /media/tv/Show Name (Year)/Season 01/episodes.mkv

  ONE folder per SHOW, seasons nested inside. Season folders sitting at
  the top level with the season in the name will be mis-matched — and
  Sonarr imports wrong matches silently rather than flagging them.

  ALWAYS review the Library Import preview table before committing.


########################################################################
#  DELETING THINGS
########################################################################

MOVIE downloaded manually (plain `movies` label, still seeding):
  Deluge -> right-click -> "Remove With Data"

ANYTHING IMPORTED BY SONARR/RADARR:
  Sonarr -> the series -> Delete (tick "Delete Files")
  Radarr -> the film -> Delete (tick "Delete Files")
  Then remove the torrent from Deluge separately if still seeding.

  Deleting in Sonarr WITHOUT ticking "Delete Files" removes only the
  database entry and leaves the files alone — which is what you want
  when fixing a bad match.

SERIES ORGANISED BY THE SCRIPT:
  rm -rf "/mnt/data_1tb/media/tv/SHOW NAME (YEAR)"

Then scan Plex so it drops from view.


########################################################################
#  ONE-TIME SAFETY SETTING
########################################################################

  Plex -> Settings -> Library -> "Allow media deletion" -> OFF

Plex then only DISPLAYS files, never deletes them. Deletion stays
deliberate: via Deluge, via Sonarr/Radarr, or via rm.


########################################################################
#  IF YOU CHANGE THE DELUGE PASSWORD
########################################################################

It lives in FIVE places. Miss one and something breaks silently:

  1. Deluge itself (Preferences -> Interface)
  2. ~/homelab/scripts/pia-port-sync.sh   line 6
  3. ~/homepage/config/services.yaml      Deluge widget
  4. Sonarr -> Settings -> Download Clients -> Deluge
  5. Radarr -> Settings -> Download Clients -> Deluge

Symptoms: Homepage shows "API Error", Sonarr/Radarr System -> Status
shows "Unable to communicate with Deluge", port sync log stops updating.


########################################################################
#  QUICK VERSION
########################################################################

MANUAL PICK (default):
  1. Deluge: add, label = tv-sonarr / movies-radarr, wait 100%
  2. Sonarr/Radarr -> Manual Import -> point at /downloads/<label>/
  3. Bazarr does subtitles automatically
  4. Plex: scan

AUTOMATED:
  1. Sonarr/Radarr -> Add New -> set Monitor -> Add
  2. Nothing else. Check Deluge if it seems stuck.

NOTHING DOWNLOADING:
  Check Deluge status (not Sonarr's queue).
  Dead release -> Queue -> X -> Blocklist and Search.
  Still dead -> click episode TITLE -> Search tab -> sort by Peers.

SCRIPT FALLBACK (unmatched / Greek content):
  1. Deluge: add, label = tv, wait 100%
  2. organize-series.sh "FOLDER"        (preview)
  3. organize-series.sh --go "FOLDER"   (do it)
  4. Deluge: remove torrent | Plex: scan
  (no automatic subtitles on this path)
