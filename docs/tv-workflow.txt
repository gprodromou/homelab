========================================================================
  HOW TO ADD A TV SEASON TO PLEX
  Quick reference — homelab media server
========================================================================

Full flow: download in Deluge -> organize with script -> scan in Plex.
The server does all the work; you just kick off each step.


------------------------------------------------------------------------
STEP 1 — DOWNLOAD IN DELUGE
------------------------------------------------------------------------

1. Open Deluge:            http://deluge.local
2. Click "Add" and paste the magnet link (or upload the .torrent).
3. BEFORE it starts, set the label to:   tv
      (right-click the torrent -> Label -> tv)
4. Wait for it to reach 100%.

   Tip: prefer 1080p releases. x265/HEVC plays fine on your TVs,
   but if a file ever stutters, grab an x264/H.264 version instead.


------------------------------------------------------------------------
STEP 2 — CONNECT TO THE SERVER
------------------------------------------------------------------------

Open Terminal on the Mac and run:

    ssh george@192.168.0.45


------------------------------------------------------------------------
STEP 3 — FIND THE EXACT FOLDER NAME
------------------------------------------------------------------------

List what's in the TV folder to get the exact download folder name:

    ls "/mnt/data_1tb/media/tv/"

Copy the folder name of the season you just downloaded
(e.g.  Some Show 2026 S01 1080p WEB x264-GROUP ).


------------------------------------------------------------------------
STEP 4 — PREVIEW WHAT THE SCRIPT WILL DO (safe, changes nothing)
------------------------------------------------------------------------

Run the organizer in DRY-RUN mode (paste the folder name in quotes):

    ~/homelab/scripts/organize-series.sh "PASTE FOLDER NAME HERE"

It prints the plan: detected show, year, and where each episode goes.
Nothing is moved yet. Check that the show name / season look correct.


------------------------------------------------------------------------
STEP 5 — RUN IT FOR REAL
------------------------------------------------------------------------

If the plan looked right, run the same command with  --go  :

    ~/homelab/scripts/organize-series.sh --go "PASTE FOLDER NAME HERE"

This creates:   Show Name (Year)/Season 0X/  ... and moves the episodes
in, then deletes the empty download folder.


------------------------------------------------------------------------
STEP 6 — REMOVE THE TORRENT FROM DELUGE
------------------------------------------------------------------------

Moving the files breaks the seed, so Deluge will show an error for it.
Clean it up:

  Open http://deluge.local
  -> right-click the torrent
  -> Remove
     (choose "Remove With Data" only if any leftover junk files remain;
      the video files are already moved, so either option is fine)


------------------------------------------------------------------------
STEP 7 — SCAN THE LIBRARY IN PLEX
------------------------------------------------------------------------

1. Open Plex:   http://plex.local
2. Hover over the "TV Shows" library in the left sidebar.
3. Click the  "..."  menu -> "Scan Library Files".
4. Wait 30-60 seconds, then refresh.

The show should appear with poster and episode info.


------------------------------------------------------------------------
IF THE SHOW DOESN'T APPEAR AFTER SCANNING
------------------------------------------------------------------------

Brand-new shows sometimes fail to auto-match. Try, in order:

  a) Wait a minute and scan again (Step 7). Often it just needs a moment.

  b) Confirm Plex can see the files (should list them):

       docker exec plex ls "/tv/SHOW NAME (YEAR)/Season 01/"

  c) In Plex, if the folder shows as unmatched:
       click the show -> "..." -> "Match" -> search the title -> pick it.


------------------------------------------------------------------------
WHEN YOU'RE DONE WATCHING
------------------------------------------------------------------------

To free up disk space, delete the show folder from the server:

    rm -rf "/mnt/data_1tb/media/tv/SHOW NAME (YEAR)"

Then scan Plex again (Step 7) so it drops the removed show.


========================================================================
  QUICK VERSION (once you're comfortable)
========================================================================

  1. Deluge: add torrent, label = tv, wait for 100%
  2. ssh george@192.168.0.45
  3. ls "/mnt/data_1tb/media/tv/"
  4. ~/homelab/scripts/organize-series.sh "FOLDER"        (preview)
  5. ~/homelab/scripts/organize-series.sh --go "FOLDER"   (do it)
  6. Deluge: remove the torrent
  7. Plex: TV Shows -> ... -> Scan Library Files
